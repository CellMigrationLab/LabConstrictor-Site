➕ Validate & Add Submission

Upload both files by dragging them in or browsing for them. Not sure how to get the requirements file? The previous chapter shows how.

Validate & Add Submission checks that both files are there and that the requirements file is valid (it must list pinned versions, like pandas==2.2.2). If a file is missing, the form says so (for example "Please upload a Jupyter Notebook file."). If it passes, the notebook is added to the submission list.

🚀 Create pull request

The button works once a repository address is given. A token is a password-like code you create on GitHub (the form takes a classic personal access token); the guide shows how. Never type a real token on a page like this one.

A pull request opens in your repository with your notebooks. Merge it (the guide "Accept a pull request" shows how). After the merge an automatic workflow checks your notebook and its dependencies. The guide says that if the check fails, for example because of a dependency conflict, the merge is undone automatically; you then read the log, fix the notebook or requirements and upload again.
