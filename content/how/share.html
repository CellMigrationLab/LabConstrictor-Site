Step

  • The repository is public and has a license.
  • labconstrictor-app.yaml is in the repository root.
  • If you offer installers, the latest GitHub release carries them.
  • Colab links point to colab.research.google.com; you choose which notebooks are listed.

Open the submission form (a GitHub issue form linked from the Submit page) and give the address of your repository. That is all you send: the registry stores only a pointer, so you never need to resubmit when you publish a new version.

A bot checks the manifest and your release and tells you what to fix. When everything passes, it opens a pull request that adds your app to the registry.

A maintainer merges it and your app appears at the next site build (daily). Its page shows what your manifest says, with a download for each system; what the manifest leaves out is shown as "Not stated".
