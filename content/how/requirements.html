You get the file

  1. Open the Requirements Generator notebook: locally, in the same environment you use to run your notebook, or in Google Colab if that is where you ran it.
  2. Run it and give it the path of your notebook.
  3. It writes requirements.yaml for you.
  1. Write requirements.yaml yourself (a good choice if you already have a versioned requirements.txt).
  2. Open the Requirements Validator notebook, best in Google Colab.
  3. Give it the path of your file and run it to check it.

What the file contains (click a part)

dependencies: every package the notebook uses, with its version, one per line starting with a hyphen and a space.

description: a short description of the notebook and its purpose.

python_version: the version of Python the notebook was run with.

This is the example from the guide. Real files may carry more fields.
