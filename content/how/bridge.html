Experimental. The plugins are untested on some systems and may change; each plugin's guide says what stage it is at.

Step

At install time, a hook looks for <package>_lc_tools in the app's Python, installs the labconstrictor-tools package, and registers the app on the computer. If this step fails, the installation still finishes and a note goes to a log file; the tools are then simply not available. The Windows hooks have not yet been run on Windows.

The plugin reads the declaration (no tool is run) and draws a field for each parameter, so every tool of the app gets a form without any interface code. You choose the app and the tool in the plugin: Plugins > LabConstrictor tools in napari, Plugins > LabConstrictor > LabConstrictor Tools... in Fiji, Extensions > LabConstrictor tools... in QuPath.

The tool runs in the app's own Python environment, in a separate process. The image software never imports the app's packages, so apps with conflicting dependencies can live side by side.

The tool returns

The host shows it as a new layer (napari) or window (Fiji).a table.a points layer, point regions of interest or point annotations. The interactive demo shows a whole run in napari and Fiji with example data.
