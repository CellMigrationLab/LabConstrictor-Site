When the workflow runs

Sync with Template Repository

Runs every Monday at 09:00 UTC; you can also start it from the Actions tab.

The run ends without opening a pull request. Nothing in your repository changes.

A pull request opens with the changes that bring your repository to the new template version. Its title is Sync template to version followed by the new version number. Review it and merge it as you would any pull request; this can include updates to your GitHub workflow files.

The run stops with an error: Synchronization setup required. No update pull request is created, so your repository stays on the template version it has.

The one-time setup that decides this

  1. Create a token that is limited to your repository, with read and write permission for Contents, Pull requests and Workflows.
  2. Save it in the repository as the secret LABCONSTRICTOR_SYNC_TOKEN (Settings, Secrets and variables, Actions).
  3. When the token expires, create a new one and update the secret.

The guide has the exact clicks, with pictures. Never type a real token on a page like this one.
