The user downloads the installer for their system from the release or the app's page. The installers are not code-signed yet, so Windows and macOS may warn; the install guide shows how to continue.

The wizard asks for the installation type (on Windows: Just Me, recommended, or All Users) and the folder, and offers to create shortcuts.

The installer creates a private environment for the app, then a post-install script installs the packages from the app's requirements (the GPU versions when an NVIDIA GPU is detected, otherwise the CPU ones) and, when the app has one, the package from src. This needs an internet connection and can take a while. If your app declares tools, the same script registers them (see the bridge chapter).

The app appears in the Start menu or Applications folder (or the applications menu on Linux). Opening it starts JupyterLab in the browser with the Welcome notebook, which lists the app's notebooks. See every Windows step in the interactive demo (the "Install the app (Windows)" part).
