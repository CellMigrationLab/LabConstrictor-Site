In the notebook

import celltools
from celltools import my_script
import celltools   # installed with pip

In src: upload the folder to src in your repository. Every folder you import needs its own __init__.py (it can be empty). Your notebooks then import it as a package, and the app's installer carries it.

As a pip package: the package is published somewhere pip can find it, and its name goes into the notebook's requirements.yaml (next chapter) so it is installed with the app's other packages.

Both: the desktop app can use the code in src while a Colab run installs the published package (for example with a pip install in a Colab-only cell, as in the first chapter). NucleiSky is built this way: its code is in src and a Colab run installs it from PyPI.
