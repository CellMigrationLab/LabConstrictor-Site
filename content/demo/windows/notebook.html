NucleiSky2D App

NucleiSky is a constellation-based registration framework that aligns microscopy images by matching the spatial arrangement of cell nuclei. It estimates a 2D similarity transform (rotation, uniform scale and translation) between images.

Adaptive Matching Strategy

This step runs a sequential cascade of matchers. It tries algorithms one by one using default settings until a valid transformation is found. The order of matchers is determined by the number of nuclei in the crop.
