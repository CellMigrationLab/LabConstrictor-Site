# Find your problem

Find what you see in the left column, then follow the link on the right. Every row goes to a page that already describes it. If yours is not here, use the **Report a problem** link on the app's page (when the repository has an issue tracker), or open an issue in [this site's repository](https://github.com/CellMigrationLab/LabConstrictor-Site/issues/new) if the problem is with the site.

## An app on your computer

| You see | Go to |
|---|---|
| "Windows protected your PC" when you run an installer | [Install on Windows](../install/index.md#windows): choose More info, then Run anyway |
| macOS refuses to open the `.pkg` file | [Install on a Mac](../install/index.md#macos): the Open Anyway button in Privacy & Security |
| An installer for Linux does not start | [Install on Linux](../install/index.md#linux) |
| The app still appears in Windows' list of installed apps after uninstalling | [Troubleshooting an installed app](../troubleshooting-installed-app/index.md) |
| JupyterLab does not start and Windows reports a certificate (ASN.1) error | [Troubleshooting an installed app](../troubleshooting-installed-app/index.md) |
| The app opened and you do not know what to do | [Open and use an app](../using-apps/index.md) and [Use notebooks after installation](../notebook-usage/index.md) |
