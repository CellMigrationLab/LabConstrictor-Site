# Open and use an app

You installed a LabConstrictor app ([how to install](../install/index.md)). The path from here: open it, try the app's example, then use your own data.

## Open it and run its first cell

Start the app from the Start Menu (Windows), the Applications folder (macOS) or your applications menu (Linux). The [notebook usage guide](../notebook-usage/index.md) shows this with pictures. JupyterLab opens in your browser with the **Welcome notebook**; run its first cell to show the table of the app's notebooks, then open the one you want and follow the instructions written in it.

Want to see the idea first? The [interactive demo](../../demo/index.md) lets you try a notebook, napari and Fiji with example data before you install anything.

## Try the app's example

Look for an example in the app's documentation (the **Documentation** or **README** link on its page in the [App Centre](../../apps/index.md)). If it has one, run it first and compare with the result it describes.

## Keep your results

Where a notebook writes its results is set in that notebook. Note the folder it names before you close JupyterLab, and copy what you want to keep.

## Use it without installing

Many apps also run in Google Colab. The app's page in the [App Centre](../../apps/index.md) lists its Colab notebooks and, when it has one, a pip command.

## Something went wrong

- Check the [install guide](../install/index.md): Windows and macOS warn about installers that are not code-signed yet, and both have a way to continue.
- [Find your problem](../help/index.md) lists what you may see and where each is explained.
- Open an issue in the app's repository (linked as **Report a problem** on its page, when the repository has an issue tracker).

## Next

Read the app's own documentation. Every app page has a **Using it** section that links to it, or to the app's README on GitHub when the authors have not written a separate one. What an app does, and what its notebooks expect, is described there, not on this site.
